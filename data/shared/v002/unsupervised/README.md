# 기간별 비지도 공통 자료

전체 10개 표를 CSV·Parquet로 공유한다. 2026Q3까지 수출금액도 사용자 지시로 포함했다.
모델 입력은 country_window_features에서 eligible_for_fit=true인 행의 gdp_per_capita_usd·population·internet_users_pct 세 열이다.
100행 모두 보존했으며 현재 82행은 세 지표가 있다. 최신 18행의 인터넷은 원천 결측이다. 국가·수출 자료는 삭제하지 않았다.
과거 네 구간은 3년, 마지막은 2025-01~2026-09의 21개월이다. 최신 거시는 2025년 관측값이다.
나머지 9개 표는 연간 원천·지표 품질·국가/제품 수출·변화 설명 자료이며 세 모델 입력에 자동 추가하지 않는다.
표준화·군집은 아직 미적합이다. 공통 변환기·중심을 사용하고 실제 관측 연도를 표시한다.
