# 공통 전처리·데이터 배포 기준

이 문서는 전처리 시 적용할 규칙이다. 세 원천 처리·지도학습 통합·시차·후보 생성과 공유 v001 확정을 완료했다. 원천 공개시점·빈티지는 미검증이며 현재 수정치 기반 실험으로 구분한다. [결합·분리 참고 사양서](dataset_release_reference.md)를 함께 대조한다.
DB는 사용하지 않는다. 컬럼 정의는 [데이터 명세](data_dictionary.md), 원천 확인 수준은 [원천 안내](data_sources.md)를 따른다.

## 1. 수집 전 확인

- `python scripts/check_config.py`로 국가·제품·기간·변수 설정을 점검한다. 인증키는 로컬 `.env`에 입력한다.
- 원천별 한 국가·한 제품·한 달의 샘플로 인증, 국가코드, HS 6자리 조회, 금액·중량 단위, 오류·빈 응답을 먼저 확인한다.
- API 접속 성공과 20개국 전체 기간 확보는 별개다. 월별·국가별·제품별 가용성 표를 만든 후 대량 수집한다.

## 2. 원본 보존과 정규화

- `data/raw/<source>/<snapshot>/`에 원본 응답과 비밀값을 제거한 요청 조건·수집시각을 보존한다. 같은 스냅샷을 덮어쓰지 않는다.
- 재시도·페이지 순회·응답 건수 제한을 확인한다. 인증 오류, 제한에 걸린 응답, 미완료 페이지를 정상적인 무역 0으로 해석하지 않는다.
- 국가 ISO3, HS 문자열, 월, USD, kg로 맞추고 `data/interim/`에 저장한다. 원천 코드·HS 판본·통계영역·평가 기준은 남긴다.
- 한국 수출은 관세청을 우선한다. Comtrade 연결은 겹치는 기간의 금액·범위 확인 후 결정하며 같은 거래를 더하지 않는다.
- 상대국 전체 수입과 한국산 수입은 상대국 신고 자료끼리 점유율을 계산한다. 한국 신고 수출액을 CIF 수입시장 분모와 혼합하지 않는다.

## 3. 분기 패널과 품질 판정

- 국가×HS×월의 유일성을 확인하고 금액·순중량을 분기 합산한다. 3개월 확보 여부와 잠정·확정·추정 상태를 함께 보존한다.
- 일부 월만 있으면 `partial`로 표시한다. 빈 응답·미신고·수집 실패는 결측이며, 원천이 명시한 실제 0만 0으로 인정한다.
- 중량이 0·결측이면 단가는 null이다. 분기 단가는 분기 금액 합계/중량 합계이며 월별 단가 평균으로 대체하지 않는다.
- 미완전 분기는 완전한 학습·평가 정답으로 쓰지 않는다. 2026Q4 일부 실적은 진행 중 정보로 분리한다.
- 전체 후보 격자는 20×8×55=8,800분기 행이다. 이는 2013Q1~2026Q3의 점검 기준이며 실제 확보 행 수나 유효 학습 표본 수가 아니다.
- 완성 패널은 `data/processed/`, 품질표는 `reports/`에 저장한다. 누락·중복·제외 사유·원천 연결 결과를 기록한다.
- 관세청은 `products.yaml`의 `customs_aggregation` 기준을 모든 지정 국가·제품·기간에 공통 적용한다. 명시적인 `총계`만 집계에서 제외하고 HS6 제품군별 조회 상세를 합산한 뒤 원천 수출금액 총계와 검산한다. 코드 길이의 혼재만으로 월·분기 전체를 보류하지 않는다. 원본 상세·코드·품명과 처리 근거를 남긴다.
- 관세청 v001은 26,400개 월 격자와 8,800개 분기 격자를 생성했다. 3개월 금액·중량이 확인된 분기는 7,384개이며 [처리 결과](../reports/customs_v001_preprocessing.md)를 검토한다.
- v002는 당시 립 제품만 반영한 이력이다. 현재 v003은 20개국×8개 제품을 전수 대조해 기존 자리수 혼재 월별 30행·분기별 12행을 모두 반영했다. 분류 보류는 0개이며 3개월이 확인된 분기는 7,396개다. [현재 전체 대조 결과](../reports/customs_v003_all_country_product_review.md)를 따른다.
- 관세청 v003은 사용자 확정본이다. Comtrade v001은 세 용도 `world_import`·`korea_import`·`export_comparison`을 분리해 64,649행을 모두 보존했다. UNSD 집계 표시·추정 중량·판본 차이만으로 행을 제외하지 않는다. HS6·세계 상대국 0의 집계값은 중복 총계가 아니며 이미 HS6인 원본을 하위 코드처럼 다시 합산하지 않는다.
- Comtrade 순중량은 `netWgt`만 사용하고 `qty`·`altQty`는 단위 코드와 함께 원문을 보존한다. 순중량 null·0·추정 여부는 금액의 완전성과 분리한다. 금액 actual은 조회된 관측값을 뜻하며 공개일·최종 확정 여부를 뜻하지 않는다.
- 수입금액은 primaryValue와 CIF/FOB 필드를 대조해 평가 기준을 보존한다. 월별 점유율은 같은 신고국·HS·월·판본·평가 기준의 한국산/전체 수입이다. 분기 점유율은 양쪽 모두 3개월 확보된 금액 합계끼리 나누며 월별 점유율을 평균하지 않는다. 분모 0·구성값 결측·기준 불일치·한국산이 전체를 초과하는 경우는 해당 점유율만 null 및 사유를 남기고 원래 금액은 보존한다.
- Comtrade 전체 대조는 [v001 보고서](../reports/comtrade_v001_preprocessing.md), 480개 국가·제품·용도 조합은 [범위표](../reports/comtrade_v001_country_product_audit.csv)를 따른다. 시장 결측을 0으로 채우거나 특정 국가를 제거하지 않는다. 공개시점 결합과 최종 학습 표본 판단은 다음 단계다.

## 4. 예측 기준시점과 독립변수

- `origin_quarter`는 마지막 관측 분기, `origin_cutoff_at`은 실제 정보 마감시각이다. 분기 말과 공개일을 같은 날로 간주하지 않는다.
- origin 이후 분기의 실제값은 입력에서 제외한다. 원천 공개일이 마감시각을 넘으면 origin 이전 기간의 값도 사용할 수 없다.
- lag1=origin, lag2=origin−1, lag4=origin−3으로 고정한다. 최근 4분기 통계는 origin에서 끝내고 전년 동기 비교는 origin−4를 사용한다.
- 시장·거시지표는 마감시각까지 공개된 가장 최근 값만 결합한다. 연간 수입금액을 4개 분기의 실제 수입금액으로 복제하지 않는다.
- World Bank의 현재 조회값은 과거 빈티지를 보증하지 않는다. 공개일 근거가 없으면 가정을 명시한 제한적 검증으로 보고하거나 해당 변수를 제외한다.
- 학습 시작 전 이력이 부족한 시차는 결측 표시한다. 결측 정답은 학습에서 제외하며, 과거 추가 수집 여부와 변수 결측 처리 기준을 기록한다.

## 5. 시간 분할과 학습 변환

| 용도 | 대상 분기 | 처리 |
|---|---|---|
| 기본 학습 대상 | 2013Q1~2021Q4, 36분기 | 대상 분기 기준, 각 적합 시점에 공개된 정답만 학습 |
| 검증 대상 | 2022Q1~2025Q4, 16분기 | 기준시점 이동, h=1~5 평가·h=2~5 우선 비교 |
| 최종 테스트 | 2026Q1~Q3, 3분기 | 가용성 확인 후 잠금 모델 평가, origin=2025Q4·h=1~3 |
| 운영 예측 | 2027Q1~Q4 | 2026Q3 관측이면 h=2~5, Q4 확보 후 h=1~4 |

- 검증은 기준시점을 이동하며 확장 학습한다. 각 적합 시점에 공개된 학습 정답만 사용한다. 미래 검증 정답으로 이전 기준시점의 모델을 학습하지 않는다.
- 인코더·결측 대체기·스케일러는 매 적합 구간에서만 학습한다. 전체 기간 적합, 미래 방향 보간, 무작위 행 분할은 사용하지 않는다.
- 수치 결측은 학습 중앙값과 결측 표시를 기본값으로 한다. 학습에서 전부 결측인 컬럼의 제외 기준과 최종 컬럼 목록을 저장한다.
- 최종 테스트 전에 모든 모델·변수 선택을 잠근다. 테스트 origin의 정보 마감 이후 공개된 2025년 자료는 모델 선택에도 사용할 수 없다.
- 최신 3분기 테스트에는 h=4~5가 없다. 해당 거리와 4분기 합계 성능은 과거 검증에서 별도 보고한다.

## 6. K-means 입력

- 국가×분석기간 한 행, 1인당 GDP·인구·인터넷 이용률 세 지표로 구성한다. 과거 네 구간은 3년 평균, 최신은 2025~2026Q3의 실제 확보 연간 지표와 관측 연도를 사용한다. 전체 100행·세 지표 확보 82행을 보존한다.
- 공개 근거와 원래 값을 보관하고 StandardScaler는 모델 파이프라인에서 적합한다. 세 지표가 부족한 국가는 미분류로 남긴다.
- 군집 번호는 매출 순위나 지도학습 입력으로 쓰지 않는다. 기본 k=3은 실험 시작값이며 최종 k는 결과 확인 후 정한다.
- World Bank v001은 연간 long 1,680행·wide 280행을 생성하고 1,560개 원본 행을 모두 보존했다. null이 담긴 원본 20행과 조회 행이 없는 2026년 120셀을 구분한다. 연간 값의 분기 합산·분기 복제·결측 대체는 하지 않는다.
- 세 지표가 20개국 모두 있는 최신 관측 연도 2024의 군집 후보 20행을 별도 저장했다. latest_common_released_year의 공개 근거는 미확인이므로 후보 상태이며, 원래 지표를 보존하고 학습·표준화·군집 부여는 후속으로 둔다. [전수 검토 결과](../reports/world_bank_v001_preprocessing.md)를 따른다.
- World Bank CSV는 원본 빈 문자열과 null을 구분하기 위해 `\N`을 null 표식으로 쓴다. manifest의 csv_null_value와 자료형을 사용하거나 Parquet를 읽는다. 최종 공유 파일의 CSV 표식·스키마를 확정할 때 원천별 읽기 규칙을 다시 검증한다.

## 7. 팀원 배포와 완료 조건

- 검토 완료 후 새 버전 `data/shared/<version>/`에 학습·검증 파일과 국가 군집 입력을 배포한다. 파일명은 `train.parquet`, `validation.parquet`, `country_indicators.parquet`를 기본으로 하고 CSV 대체 여부를 manifest에 명시한다.
- `manifest.json`에 실제 파일명·행 수·스키마·기간·원천·수집시각·가용성 가정·SHA-256을 기록한다. 실제 파일 생성·검증 전 `not_generated`를 변경하지 않는다.
- 최종 테스트 원본 캐시는 `.private/evaluation/`에 유지하고, 입력·정답은 사용자 지시로 `data/shared/v002/final_test.parquet`에 공유한다. train·validation에는 테스트 행을 섞지 않는다.
- 파일을 다시 읽어 자료형·행 수·체크섬을 확인하고, 20개국·8개 제품 누락 및 시점 누수 점검 결과를 첨부한다.
- 재수집·정제 변경 시 기존 배포를 수정하지 않고 새 버전과 변경 요약을 제공한다. 팀원은 같은 버전으로 비교한다.

## 8. 지도학습 처리 후보 v002의 구성

- 후보 생성 당시에는 전체 관측자료·시차를 먼저 보존하고 공개시점·공유 승인을 미확정으로 기록했다. 해당 후보는 이력으로 유지하며 이후 공유 확정은 9절을 따른다. 비지도학습 데이터는 변경하지 않는다.
- 관측표는 국가·제품·월/분기 기준으로 관세청과 수입시장을 일대일 결합하고, 같은 달력연도의 거시 관측 문맥을 다대일로 붙인다. 원천 전체 열은 접두어·column_lineage로 보존한다. 이 관측표를 곧바로 모델 입력으로 쓰지 않는다.
- 후보 표본은 origin 이전/동일 분기의 수출 시차·이동통계, origin 동일 분기 시장 후보, 직전 달력연도 거시 후보다. 공개일·최대 허용 시차를 가정하지 않으며 전방 채우기·다른 연도 대체·모델 변환기 적합을 하지 않는다.
- 학습·검증은 각 타깃별 h=1~5, 최종 테스트는 2025Q4 origin 고정 h=1~3이다. 원천 타깃 결측·수집 전 origin 후보도 보존하고 상태를 남긴다. 정답이 없는 행은 실제 학습·정답 평가에 쓰지 않으며 후보를 보존한 개수와 고유 관측 개수를 구분한다.
- v002는 2022~2023년 타깃을 학습에서 검증으로 옮겼다. 월별·분기별 관측과 기준분기 변수·전체 후보는 보존한다. 저장 위치는 `data/processed/supervised/v002/`, 최종 테스트 후보는 `.private/evaluation/supervised/v002/`다. origin_cutoff_at은 null, training_approved는 false다. [현재 결과](../reports/supervised_v002_integration.md)·manifest 입력 목록과 후속 공개시점 확정안을 확인한다.

## 9. 확정 공유 v001

- 사용자가 지도학습 공유를 승인했다. 처리 v002의 모든 train·validation 행과 입력·식별·달력·정답·결측 표시를 `data/shared/v002/` CSV/Parquet로 저장하고 manifest를 released로 갱신했다. 원천 내부 경로는 로컬 처리표에 보존하며 공유 표에서는 제외했다.
- 공유본은 모델 입력 57개·전체 87개 열이며 정답 없는 행을 그대로 보존한다. 적합·평가에서는 target_available과 각 기준시점 조건을 확인한다. 공유본의 열 순서·자료형·체크섬·확인 한계는 manifest와 README에 기록했다.
- 실제 원천 공개일을 확인한 것은 아니다. 현재 수정치·기간 정렬 변수로 실험하며 과거 공개시점 재현을 주장하지 않는다. 비지도 자료·최종 테스트 정답·원본·개인 문서는 공유하지 않는다.
