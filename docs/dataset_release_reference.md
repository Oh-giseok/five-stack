# 전처리 자료 최종 확정·결합·분리 참고 사양서

작성일: 2026-11-03. 원천별 전처리가 끝난 뒤 공통 학습 자료를 확정·배포할 때 적용한다.
기준 문서는 [프로젝트 사양서](../PROJECT_SPEC.md)와 [전처리 기준](data_processing.md)다. 처리 후보 v002에서 검증을 16분기로 확대한 뒤 사용자 승인으로 지도학습 공유 v001을 확정했다. 과거 공개시점 근거·빈티지는 미검증으로 명시했다.

## 1. 타깃과 기준 패널

- 타깃 원천은 사용자 확정 관세청 v003의 국가×HS6×분기 수출금액(USD·FOB)이다. 예측은 2027Q1~Q4, 중량은 보조 타깃이다.
- 기준 격자는 20개국×8개 제품×2013Q1~2026Q3=8,800행이다. 모든 격자를 보존하고 실제 학습·평가 사용 여부는 별도 표시한다.
- Comtrade 한국 신고 수출은 비교용이다. 관세청과 더하거나 원천별 차이를 임의 보정·자동 결측 보충하지 않는다.

## 2. 결합 키와 행 수

| 자료 | 결합 전 유일키 | 사용 |
|---|---|---|
| 관세청 분기 | country_code, hs_code, quarter | 기준 패널·타깃 |
| Comtrade 시장 분기 | country_code, hs_code, quarter | 전체 수입·한국산 수입·점유율 |
| Comtrade 세 용도 원본 패널 | 위 키 + source_role | 용도 구분 후 시장 패널 사용 |
| World Bank 연간 | country_code, indicator_year | 기준시점에 사용 가능한 거시지표 |
| 지도학습 최종 표본 | country_code, hs_code, origin_quarter, target_quarter | 예측 거리별 입력·정답 |
| K-means | country_code + 단일 reference_year | 국가당 한 행, 별도 입력 파일 |

- 국가 ISO3·HS6 문자열·분기 형식을 통일하고 결합 관계를 검증한다. 시장은 일대일, 국가 거시지표는 다대일이며 행 증식이 있으면 원인을 확인한다.
- 원천 CSV의 null 표식과 자료형은 각 manifest로 읽는다. World Bank v001은 원본 빈 문자열 보존을 위해 `\N`을 사용한다. 최종 공유 CSV의 표식·스키마는 통일 여부를 정하고 재조회로 검증한다. Parquet의 null·자료형도 대조한다.
- 기준 패널에 왼쪽 결합하고 독립변수 부족만으로 국가·제품·정상 타깃을 일괄 삭제하지 않는다. 8,800개 관측 격자와 horizon 구성 후 학습 표본 수는 구분한다.

## 3. 시장 자료 기간 차이

- 국가별 최신 시장 분기가 달라도 국가를 제외하지 않는다. 사용한 실제 시장 분기·수집시각·공개 근거·기준시점과의 시차를 남긴다.
- 최신 값 사용은 예측 기준시점에 알려진 과거 값 중에서 선택한다. 원천이 없는 미래 구간을 실제 분기값으로 복제하지 않는다.
- 과도하게 오래된 시장값의 허용 기간은 최종 배포 전에 정한다. 현재 임의의 최대 시차·무제한 전방 채우기를 확정하지 않는다.

## 4. 공개시점과 현재 수정치

- origin_quarter는 마지막 관측 분기, origin_cutoff_at은 실제 정보 마감시각이다. 기간 말·수집일·DB 갱신일을 개별 관측값의 최초 공개일로 간주하지 않는다.
- 과거 공개일·당시 빈티지가 미확인이면 원본 값을 보존하되, 근거 확보 / 명시한 지연 가정에 따른 제한적 검증 / 해당 변수 미사용 중 적용안을 기록한다.
- 공개시점 가정 없이 누수 없는 과거 재현으로 선언하지 않는다. 최종 확정 전 미결 항목이며 현재 원천 전체를 폐기하는 사유가 아니다.

## 5. 결측·부분 분기

- 원천의 실제 0은 보존하고 미조회·미신고 원인 미확인·원천 null은 결측으로 유지한다. 금액·중량·시장 지표의 완전성을 각각 판단한다.
- 분기 금액·중량은 각각 3개월 확보 시에만 완전 값이다. observed_* 부분합은 검산용이며 정답 대체값이 아니다.
- 독립변수는 결측 표시를 제공한다. 대체값은 학습 구간에서 적합하며 미래 보간을 하지 않는다. 모델별 대체·원래 결측 허용 여부는 실험 기록에 남긴다.
- 타깃이 없는 행은 학습·정답 평가에서 제외하고 사유·개수를 기록한다. 국가·제품 행 자체와 품질 기록은 보존한다.

## 6. 수입금액·점유율·단가

- 수입 CIF/FOB와 수출 FOB는 원천별로 유지한다. 점유율은 같은 대상국·HS·기간·평가기준·판본의 한국산 수입/전체 수입이며 관세청 수출을 분자로 쓰지 않는다.
- 분기 점유율은 양쪽 3개월 합계의 비율이다. 분모 0·구성값 결측·기준 불일치·한국산이 전체보다 큰 경우 점유율만 null 및 사유를 남긴다.
- 단가는 분기 금액/분기 순중량이다. 중량 0·결측이면 null이며 원천 추정 중량 여부를 함께 남긴다. 금액을 삭제하거나 월별 단가 평균으로 대체하지 않는다.

## 7. World Bank·K-means

- 지도학습 후보는 GDP·1인당 GDP·인구·물가·환율·인터넷 이용률 6개다. 연간 지표를 분기로 합산하거나 4로 나누지 않고 당시 알려진 국가 특성으로 연결한다.
- 연간 값의 indicator_year·결측·단위·공개 근거를 보존한다. 과거 값을 연결할 때 해당 값이 몇 년도 자료인지 함께 추적한다.
- K-means는 1인당 GDP·인구·인터넷 이용률 3개, 동일 연도, 국가당 한 행이다. 값이 모두 있는 공통 연도와 당시 공개까지 확인된 공통 연도는 구분한다.
- 공개시점이 미확인인 최신 공통 연도 파일은 후보로 표시한다. 운영·역사 평가용 기준연도를 자동 승인하지 않으며 국가별 다른 연도로 빈칸을 메우지 않는다.
- StandardScaler와 K-means는 학습 단계에서 적합한다. 군집 번호는 지도학습에 자동 입력하지 않으며 원래 지표값을 덮어쓰지 않는다.

## 8. 시차·시간 분리

- lag1=origin, lag2=origin−1, lag4=origin−3이며 최근 4분기 통계는 origin에서 끝낸다. 미래 target 실제값을 입력에 쓰지 않는다.
- 학습 대상 2013Q1~2021Q4(36분기), 검증 대상 2022Q1~2025Q4(16분기), 최종 테스트 대상 2026Q1~Q3(3분기)로 target_quarter 기준 분리한다.
- 검증은 기준시점 이동·확장 학습, h=1~5 중 h=2~5 우선 비교다. 최종 테스트는 origin=2025Q4·h=1~3이며 모델·변수·설정 선택에 사용하지 않는다.
- 인코더·결측 대체·스케일러는 각 적합 구간에서만 학습한다. 학습 정답도 해당 적합 시각까지 공개된 값이어야 한다.
- 거시지표 포함·제외 비교는 같은 검증 행·origin으로 수행한다. 평가 후 최신 실적 재학습은 테스트 기록을 보존한 뒤 진행한다.

## 9. 공유와 배포 확정 조건

- 공유 파일은 train·validation·country_indicators와 manifest다. 최종 테스트 입력·정답은 팀장 로컬 .private/evaluation에서 별도 관리한다.
- 원천별 버전·SHA-256·스키마·기간·단위·결측·제외 사유·공개시점 가정·변수 목록을 함께 배포한다. 원본·전체 정제본을 자동으로 Git 공유하지 않는다.
- 저장 후 CSV·Parquet의 값·null·자료형·체크섬을 재검증하고 20개국·8개 제품별 타깃/변수 가용성을 첨부한다. 기존 배포는 덮어쓰지 않는다.

## 10. 최종 확정 전 미결 사항

| 항목 | 확정할 내용 |
|---|---|
| 공개시점·빈티지 | 원천별 근거 또는 검증에 적용할 명시적 가정 |
| 오래된 시장·거시 값 | 사용 가능한 최대 시차와 초과 시 결측 처리 |
| 학습 결측 처리 | 모델별 처리, 전부 결측 컬럼, 타깃 제외 행 목록 |
| 군집 기준연도 | 공통 값·공개 근거를 충족한 운영/평가별 연도 |
| 배포 승인 | 지도학습 공유 v001 사용자 승인 완료, 비지도 자료는 별도 |

현재 지도학습 공유 v001을 사용자 승인으로 확정했다. 기간 기준은 시장=origin 동일 분기·거시=직전 달력연도이며 공개 지연 가정이 아니다. 처리 후보의 과거 승인 상태는 보존하고 공유 승인은 별도 명세에 기록했다. origin_cutoff_at과 과거 공개일은 여전히 미확인이며 현재 수정치 기반 실험으로 구분한다. [공유 결과](../reports/shared_v001_release.md)를 참고한다. 비지도학습은 별도 진행한다.
