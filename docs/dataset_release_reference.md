# 전처리 자료 최종 확정·결합·분리 참고 사양서

작성일: 2026-11-03. 원천별 전처리가 끝난 뒤 공통 학습 자료를 확정·배포할 때 적용한다.
기준 문서는 [프로젝트 사양서](../PROJECT_SPEC.md)와 [전처리 기준](data_processing.md)다. 처리 후보 v002에서 검증을 16분기로 확대한 뒤 사용자 승인으로 지도학습 공유 v001을 확정했다. 과거 공개시점 근거·빈티지는 미검증으로 명시했다.

## 1. 타깃과 기준 패널

- 타깃 원천은 사용자 확정 관세청 v003의 국가×HS6×분기 수출금액(USD·FOB)이다. 예측은 2027Q1~Q4, 중량은 보조 타깃이다.
- 기준 격자는 20개국×8개 제품×2013Q1~2026Q3=8,800행이다. 모든 격자를 보존하고 실제 학습·평가 사용 여부는 별도 표시한다.
- Comtrade 한국 신고 수출은 비교용이다. 관세청과 더하거나 원천별 차이를 임의 보정·자동 결측 보충하지 않는다.

## 2. 결합 키와 행 수

| 자료 | 결합 전 유일키 | 사용 |
|---|---|---|
| 관세청 분기 | country_code, hs_code, quarter | 기준 패널·타깃 |
| Comtrade 시장 분기 | country_code, hs_code, quarter | 전체 수입·한국산 수입·점유율 |
| Comtrade 세 용도 원본 패널 | 위 키 + source_role | 용도 구분 후 시장 패널 사용 |
| World Bank 연간 | country_code, indicator_year | 기준시점에 사용 가능한 거시지표 |
| 지도학습 최종 표본 | country_code, hs_code, origin_quarter, target_quarter | 예측 거리별 입력·정답 |
| K-means | country_code, window_id | 국가×3년 구간, 세 지표 평균 |

- 국가 ISO3·HS6 문자열·분기 형식을 통일하고 결합 관계를 검증한다. 시장은 일대일, 국가 거시지표는 다대일이며 행 증식이 있으면 원인을 확인한다.
- 원천 CSV의 null 표식과 자료형은 각 manifest로 읽는다. World Bank v001은 원본 빈 문자열 보존을 위해 `\N`을 사용한다. 최종 공유 CSV의 표식·스키마는 통일 여부를 정하고 재조회로 검증한다. Parquet의 null·자료형도 대조한다.
- 기준 패널에 왼쪽 결합하고 독립변수 부족만으로 국가·제품·정상 타깃을 일괄 삭제하지 않는다. 8,800개 관측 격자와 horizon 구성 후 학습 표본 수는 구분한다.

## 3. 시장 자료 기간 차이

- 국가별 최신 시장 분기가 달라도 국가를 제외하지 않는다. 사용한 실제 시장 분기·수집시각·공개 근거·기준시점과의 시차를 남긴다.
- 최신 값 사용은 예측 기준시점에 알려진 과거 값 중에서 선택한다. 원천이 없는 미래 구간을 실제 분기값으로 복제하지 않는다.
- 과도하게 오래된 시장값의 허용 기간은 최종 배포 전에 정한다. 현재 임의의 최대 시차·무제한 전방 채우기를 확정하지 않는다.

## 4. 공개시점과 현재 수정치

- origin_quarter는 마지막 관측 분기, origin_cutoff_at은 실제 정보 마감시각이다. 기간 말·수집일·DB 갱신일을 개별 관측값의 최초 공개일로 간주하지 않는다.
- 과거 공개일·당시 빈티지가 미확인이면 원본 값을 보존하되, 근거 확보 / 명시한 지연 가정에 따른 제한적 검증 / 해당 변수 미사용 중 적용안을 기록한다.
- 공개시점 가정 없이 누수 없는 과거 재현으로 선언하지 않는다. 최종 확정 전 미결 항목이며 현재 원천 전체를 폐기하는 사유가 아니다.

## 5. 결측·부분 분기

- 원천의 실제 0은 보존하고 미조회·미신고 원인 미확인·원천 null은 결측으로 유지한다. 금액·중량·시장 지표의 완전성을 각각 판단한다.
- 분기 금액·중량은 각각 3개월 확보 시에만 완전 값이다. observed_* 부분합은 검산용이며 정답 대체값이 아니다.
- 독립변수는 결측 표시를 제공한다. 대체값은 학습 구간에서 적합하며 미래 보간을 하지 않는다. 모델별 대체·원래 결측 허용 여부는 실험 기록에 남긴다.
- 타깃이 없는 행은 학습·정답 평가에서 제외하고 사유·개수를 기록한다. 국가·제품 행 자체와 품질 기록은 보존한다.

## 6. 수입금액·점유율·단가

- 수입 CIF/FOB와 수출 FOB는 원천별로 유지한다. 점유율은 같은 대상국·HS·기간·평가기준·판본의 한국산 수입/전체 수입이며 관세청 수출을 분자로 쓰지 않는다.
- 분기 점유율은 양쪽 3개월 합계의 비율이다. 분모 0·구성값 결측·기준 불일치·한국산이 전체보다 큰 경우 점유율만 null 및 사유를 남긴다.
- 단가는 분기 금액/분기 순중량이다. 중량 0·결측이면 null이며 원천 추정 중량 여부를 함께 남긴다. 금액을 삭제하거나 월별 단가 평균으로 대체하지 않는다.

## 7. World Bank·K-means — 기간별 비교 v1.3

### 7.1 입력·집계·모델 기준

- 세 입력은 1인당 GDP·인구·인터넷 이용률이다. 과거 네 구간은 완전한 3개년 평균, 마지막은 실제 확보 연간 값의 평균과 observed_years를 사용한다. 마지막 구간을 3년 미완결로 차단하지 않는다.
- 마지막 거시는 현재 2025년 자료다. GDP·인구 20개국, 인터넷 중국·인도 2개국만 있다. 18개국은 실제 인터넷 원천 결측이며 20행 모두 보존한다. 2026년 연간 지표를 분기 실측값으로 만들지 않는다.
- country_window_features 100행 중 세 입력이 있는 82행이 적합 가능하다. 세 지표의 관측 연도 집합도 같아야 하며 공통 스케일러·군집 중심을 사용한다. GDP·수출·품질은 입력이 아니다.
- 지도학습 57개 입력·공유 v001·시간 분할은 유지한다. 공통 군집은 현재 수정치 기반 사후 탐색이며 과거 예측 성능이 아니다.

### 7.2 실제 구간·가용성

| window_id | 분석기간 | 세 지표 사용 가능 국가 | 기대 월 수/품목 | 집계 기준 |
|---|---|---:|---:|---|
| 2013_2015 | 2013~2015 | 20 | 36 | 세 연도 평균·36개월 수출 |
| 2016_2018 | 2016~2018 | 20 | 36 | 동일 |
| 2019_2021 | 2019~2021 | 20 | 36 | 동일 |
| 2022_2024 | 2022~2024 | 20 | 36 | 동일 |
| 2025_2026Q3 | 2025~2026Q3 | 2 | 21 | 2025-01~2026-09 실적·확보된 연간 거시 |

최근 20개국·160개 국가×품목 모두 보존한다. 이 중 품목 140개는 21개월 금액이 모두 있어 실제 기간 완전 합계를 제공한다. 20개는 실제 원천 결측이 있어 부분합을 표시한다. 2026Q4·2027은 선택 구간 밖이며 결측 셀을 만들지 않는다.

### 7.3 생성한 로컬 표·키

경로는 `data/processed/unsupervised/v002/`다. 10개 표마다 CSV·Parquet와 스키마·체크섬 manifest를 제공한다. 처리 원천이며, 사용자 승인 전체 공유 v002는 data/shared/v002에 있다. 군집 모델 결과는 아직 없다.

| 표 | 유일키 | 행 수 | 역할 |
|---|---|---:|---|
| macro_annual | 국가, indicator_year | 280 | 기존 World Bank 연간 6개 지표·메타정보 그대로 보존 |
| macro_window_long | 국가, window_id, indicator_name | 400 | GDP와 군집 세 지표의 구간 평균·부분 평균·연도·원천 |
| country_window_profile | 국가, window_id | 100 | GDP·세 지표 평균과 품질 메타정보 |
| country_window_features | 국가, window_id | 100 | 세 지표·실제 관측 연도와 eligible_for_fit; 현재 82행 적합 가능 |
| country_product_export_annual | 국가, HS, year | 2,240 | 2013~2026년 제품별 연간 수출 |
| country_export_annual | 국가, year | 280 | 전체 8제품 연간 수출 |
| country_product_export_window | 국가, HS, window_id | 800 | 제품별 3년 수출 |
| country_export_window | 국가, window_id | 100 | 전체 8제품 3년 수출 |
| country_window_context | 국가, window_id | 100 | 경제·전체 제품 수출·인접 구간 변화 결합 |
| country_product_window_context | 국가, HS, window_id | 800 | 경제·제품 수출·인접 구간 변화 결합 |

국가와 window_id로 연결한다. HS는 수출 맥락만 구분하며 HS 반복 행으로 군집을 적합하지 않는다. 프로필→국가 맥락은 일대일, 프로필→제품 맥락은 일대다를 검증한다.

### 7.4 완전성·변화·공개

- expected_window_value_cells는 실제 선택 월 수×제품 수다. 과거 구간은 36/288, 마지막 21개월 구간은 21/168이다. 2026년 year 행도 end_month=2026-09, 9/72를 기준으로 집계하며 연간 확정치가 아니다.
- export_value_usd는 선택 기간 모든 금액 확보 시 합계다. observed_export_value_usd는 관측 부분합이다. 관측된 실제 0과 결측을 구분한다.
- start_month·end_month·period_month_count·is_short_period·period_status로 실제 기간을 보존한다. 마지막 상태는 observed_to_cutoff다. 미래 달을 분모에 넣지 않는다.
- 과거 네 구간 macro value는 완전 평균이며 마지막 value는 available_annual_mean이다. complete·value_basis·observed_years·valid_year_count로 차이를 표시한다. 부분 기간이라는 사유만으로 값이 있는 입력을 null로 지우지 않는다.
- 인터넷 변화는 %p, 경제지표 변화는 %이며 실제 관측 연도 수 차이를 표시한다. 수출은 같은 기간 길이일 때만 인접 증감률을 계산한다. 마지막 21개월과 이전 36개월의 직접 비율은 null이며 export_value_comparison_status에 사유를 남긴다.
- 원천 결측·수집일·공개일 미검증은 구분한다. GDP·1인당 GDP는 명목 USD이며 개인 소득·PPP가 아니다.
- 로컬 자료는 2026년 테스트 금액을 보존한다. 사용자 추가 승인으로 전체 비지도 맥락과 테스트 정답을 data/shared/v002에 공유한다. 원본 캐시는 유지하고 공유본의 disclosure_status를 team_shared_by_user_instruction으로 기록한다.

### 7.5 화면·검수

- P02B 상단의 `지표 기준연도`는 `분석기간`으로 바꾼다. `군집 분포 / 기간별 변화`를 전환하며 기간·지표·제품 선택은 배포 결과 조회다.
- 군집 분포는 X=구간 평균 1인당 GDP, Y=구간 평균 인터넷 이용률, 점 면적=구간 평균 인구, 색상=공통 실행 군집이다. 축 범위·인구 크기 척도는 구간 간 고정한다.
- 기간별 변화는 X=분석 구간, Y=선택 지표 하나다. 실제 결측은 선을 끊고 최근 구간의 확보된 경제지표와 21개월 수출은 실제 기간·관측 연도를 표시해 조회한다. 표는 구간 값·변화·실제 연도·관측 범위를 연결한다.
- 화면은 차트 1개+표 1개다. 학습된 군집 번호가 아직 없으면 분포를 학습 결과처럼 표시하지 않는다.
- 전체 국가·제품·구간·연도·세 지표·원천 평균/금액·중복·키·CSV/Parquet·기존 공유본 불변을 전수 검수한다. 상세 결과는 [전처리 보고서](../reports/unsupervised_v002_preprocessing.md)와 [검산 기록](../reports/unsupervised_v002_audit.json)을 따른다.

## 8. 시차·시간 분리

- lag1=origin, lag2=origin−1, lag4=origin−3이며 최근 4분기 통계는 origin에서 끝낸다. 미래 target 실제값을 입력에 쓰지 않는다.
- 학습 대상 2013Q1~2021Q4(36분기), 검증 대상 2022Q1~2025Q4(16분기), 최종 테스트 대상 2026Q1~Q3(3분기)로 target_quarter 기준 분리한다.
- 검증은 기준시점 이동·확장 학습, h=1~5 중 h=2~5 우선 비교다. 최종 테스트는 origin=2025Q4·h=1~3이며 모델·변수·설정 선택에 사용하지 않는다.
- 인코더·결측 대체·스케일러는 각 적합 구간에서만 학습한다. 학습 정답도 해당 적합 시각까지 공개된 값이어야 한다.
- 거시지표 포함·제외 비교는 같은 검증 행·origin으로 수행한다. 평가 후 최신 실적 재학습은 테스트 기록을 보존한 뒤 진행한다.

## 9. 공유와 배포 확정 조건

- 현재 공유 v002는 train·validation·final_test와 비지도 10개 표를 포함한다. 최종 테스트 정답도 사용자 지시로 팀원 전체가 조회한다. `.private/evaluation`은 원본 처리 캐시이며 배포 경로가 아니다.
- 원천별 버전·SHA-256·스키마·기간·단위·결측·제외 사유·공개시점 가정·변수 목록을 함께 배포한다. 원본·전체 정제본을 자동으로 Git 공유하지 않는다.
- 저장 후 CSV·Parquet의 값·null·자료형·체크섬을 재검증하고 20개국·8개 제품별 타깃/변수 가용성을 첨부한다. 기존 배포는 덮어쓰지 않는다.
