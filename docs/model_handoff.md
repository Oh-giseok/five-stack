# 모델 학습·인계 기준

이 문서는 팀원에게 전달할 실험·산출물 규격이다. 학습·평가·예측 스크립트는 아직 미구현이다.

현재 확정 전체 공유본은 `data/shared/v002/`다. 학습·검증·final_test 480행과 비지도 10개 표를 모두 제공한다. 학습 2013Q1~2021Q4(36분기)·검증 2022Q1~2025Q4(16분기), 각각 28,800행·12,800행을 공유한다. 정답 결측과 수집 전 origin도 보존했으므로 적합 시 원천 정답·기준시점을 확인한다. manifest의 feature_columns 57개만 입력한다. 기존 로컬 테스트 후보는 원본 캐시로 보존하고 팀원은 공유 폴더의 final_test.parquet와 unsupervised/를 사용한다.

사용자 공유 승인은 과거 공개시점·빈티지 검증을 뜻하지 않는다. 현재 수정치와 기간 기준으로 정렬한 변수이며 origin_cutoff_at은 null이다. 현재 자료 기반 실험으로 명시하고, 과거 공개시점까지 재현하는 평가에는 별도 근거·가정이 필요하다. [공유 파일 안내](../data/shared/v002/README.md)를 따른다.

## 공통 실험 조건

- 같은 `data/shared/<version>/`와 manifest를 사용한다. 타깃은 한국→대상국 제품별 분기 수출금액 USD·FOB다.
- 국가·제품 통합 패널 모델로 h=1~5를 학습하고 h=2~5 성능을 우선 비교한다. 입력에 예측 거리와 대상 달력 정보를 포함한다.
- 16분기 검증은 target_quarter 기준이다. 각 origin/cutoff 이후 공개된 학습 정답은 제외한다. 예를 들어 2022Q1·h=5의 origin은 2020Q4이므로 그때 2021년 정답을 학습에 사용하지 않는다. 후보 파일 전체 train 행을 모든 origin에 그대로 적합하지 않는다.
- Seasonal Naive와 XGBoost·LightGBM·CatBoost를 비교한다. 기본 실험 후 여유가 있으면 원하는 추가 모델을 같은 데이터·평가 조건으로 실험할 수 있다.
- `configs/models/`는 초기값이며 최적 설정이 아니다. 변경한 값은 실험 폴더에 별도 저장하고 공통 YAML을 실험마다 덮어쓰지 않는다.
- 거시지표 포함·제외 실험은 동일한 검증 행과 origin에서 비교한다. 최종 테스트는 모델·변수 선택에 사용하지 않는다.

## 지도학습 제출물

`artifacts/<run_id>/`에 아래 항목을 함께 보관한다. 용량이 큰 파일은 팀에서 정한 전달 경로를 쓰고 경로와 체크섬을 남긴다.

| 항목 | 필수 내용 |
|---|---|
| 모델·변환기 | 모델 본체, 범주 인코더, 결측 대체기, 최종 컬럼 순서, 타깃 변환·역변환 |
| 실행 메타정보 | run_id, model_id, 데이터 버전·체크섬, 코드 커밋 또는 변경 상태, 실행시각, 라이브러리 버전 |
| 입력 조건 | 사용 변수, with_macro/without_macro, 적합 기간, 기준 분기·정보 마감시각, horizon, 제외 행 사유 |
| 학습 설정 | 파라미터, 난수 시드, 인코딩, 결측·음수 예측 처리, 재학습 방법 |
| 검증 결과 | 행별 정답·예측, 거리별·국가별·제품별 지표, 기준선 비교, 연간 합계 검증 |
| 로드 방법 | 입력 스키마, 로드·예측 예제, 모델 재적합 없이 같은 예측을 재현한 확인 결과 |

모델마다 범주형 처리는 다를 수 있다. XGBoost·LightGBM 기본값은 학습 구간 One-hot, CatBoost는 문자열 범주형이다.
수치 결측 대체기는 적합 구간에서만 학습한다. 배포 시 음수 매출은 0으로 제한하며 평가에도 같은 후처리를 적용한다.

## 공통 검증 지표

- 주 지표 WAPE = `100 × Σ|실제−예측| / Σ|실제|`. 분모가 0인 그룹은 null·해당 건수를 보고한다.
- MAE·RMSE는 USD, sMAPE는 `평균(200 × |실제−예측| / (|실제|+|예측|))`로 계산한다. 실제·예측이 모두 0인 행의 sMAPE는 0으로 둔다.
- 전체 WAPE는 전체 오차·실제 합계에서 계산하며 국가별 WAPE의 단순 평균으로 대체하지 않는다. 제외·결측 행 수를 기록한다.
- h=1~5, 국가, 제품별 결과를 보고한다. 같은 국가·제품·origin에서 4분기 예측과 정답이 모두 있는 경우 연간 합계 오차도 평가한다.
- Seasonal Naive는 대상 분기와 같은 계절 중 origin까지 관측된 가장 최근 분기를 사용한다. h=5에서 아직 관측하지 못한 target−4를 읽지 않는다.

## K-means 제출물

- 최신 입력은 로컬 비지도 v002의 country_window_features다. 국가×구간 100행과 세 수치 열만 사용한다. 현재 82행 적합 가능이며 나머지 18행은 최신 인터넷 지표 실제 결측이다.
- 기간은 과거 네 3년 구간과 2025-01~2026-09다. 최신 구간에 36개월·3개 연도를 강제하지 않는다. 수출은 21개월, 경제지표는 현재 확보된 2025년 연간 관측임을 표시한다.
- 마지막 구간도 세 지표가 있으면 사용할 수 있다. 관측 연도 집합 일치·원래 값·부분 평균 기준을 기록한다. 과거 값 대체나 2026년 거시 실측 생성은 하지 않는다.
- 공통 StandardScaler·K-means를 사용하고 k=2·3·4의 해석·크기·silhouette를 비교한다. 변환기·중심·시드·입력 순서·환경·실제 적합 구간을 제출한다. 단일 국가 반복 관측은 독립 국가 수 증가가 아니다.
- 결과 키는 cluster_run_id+국가+window_id다. 번호는 순위가 아니며 지도학습 자동 입력이 아니다. GDP·수출·품질·제품 반복 행은 세 군집 입력에 넣지 않는다.
- P02B는 군집 분포/기간별 변화, 차트 1개+표 1개다. 최신 구간의 실적을 조회하고 기간 길이와 거시 관측 연도를 함께 표시한다.
- 현재 수정치 기반 사후 분석이며 과거 공개시점 재현은 미검증이다. 2026년 테스트 금액과 수출 맥락은 사용자 지시로 팀 전체 공유한다. 학습·검증·테스트 역할은 유지하고 테스트를 본 뒤 조정한 모델은 그 사용 이력을 기록한다. [참고 사양서 7절](dataset_release_reference.md)을 따른다.

## 최종 테스트와 화면 연결

- 화면 기능·이동·데이터 관계와 배치는 [GEM 전체 설계 확정안 PDF](GEM_전체설계_확정안_v1.4.pdf) 및 [컨플루언스 확정 문서 모음](https://kimdonggyu114.atlassian.net/wiki/spaces/VVhnfE1g5PNR/pages/2457601/GEM+v1.3)을 따른다. 한 화면 결과는 최대 2개이며 지금은 UI 코드·운영 산출물 생성 전이다.
- 새 논리 ERD의 실행·평가·시나리오 필드는 후속 구현 계약이다. 이미 배포한 학습 파일·57개 입력을 변경하지 않는다. 기존 출력 컬럼명은 공통 데이터 명세를 유지한다.
- 팀장은 모델 선택을 완료한 후 2026Q1~Q3 완전성을 확인하고 잠금 테스트를 실행한다. 2025Q4 origin에서 h=1~3을 평가하며 h=4~5 한계도 함께 보고한다.
- 테스트 기록을 보존한 뒤 확보한 최신 실적까지 운영용으로 재학습한다. 테스트를 보고 설정을 바꾸면 같은 테스트를 독립 평가로 주장하지 않는다.
- 운영 출력은 `artifacts/production/`의 예측·군집 Parquet와 manifest다. 실험 파일을 직접 화면 기본 경로로 쓰지 않는다.
- manifest에는 예측 기준시각·최신 실적 분기·모델/데이터 버전·실제 파일명·체크섬을 기록한다. 출력 컬럼은 [데이터 명세](data_dictionary.md)를 따른다.
- 20×8×4=640개 매출 예측은 전체 조합이 생성된 경우의 기대 행 수다. 누락이 있으면 화면에 표시하며 임의 수치로 채우지 않는다.
- 화면은 저장된 예측을 조회한다. 국가를 선택할 때마다 재학습하지 않는다. 생산 시나리오는 목표 점유율·단가·재고 등 입력이 확보된 뒤 계산한다.

## 전체 공유 정책 — 2026-11-04 사용자 지시

현재 배포는 [전체 공유 v002 안내](../data/shared/v002/README.md)다. 학습 28,800행·검증 12,800행·최종 테스트 480행(정답 447/결측 33)과 비지도 전체 10개 표를 포함한다.
지도학습 입력 57개·전체 87개 열·시간 분할·원래 값·null을 유지한다. 비지도 입력은 100행 보존·82행 세 지표 확보이며 최신 구간은 2025-01~2026-09다.
팀장 전용 보관 제한을 해제하고 최종 테스트 정답·2026년 수출 맥락까지 공유한다. 원본 처리 캐시는 이동·삭제하지 않는다. 테스트 파일 공유와 학습 입력 사용은 구분하며 테스트로 모델을 조정했다면 해당 결과의 사용 이력을 기록한다.
과거 v001·로컬 전처리 보고서·Confluence v1.3의 비공개 정책은 당시 처리 이력이며 이 전체 공유 정책과 v002 manifest를 우선한다.
