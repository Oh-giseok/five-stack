# GEM 프로젝트 포트폴리오

GEM(Global Export Management)의 기획·구현 결과와 팀 협업 과정을 소개하는 **프로젝트 포트폴리오 완성본**입니다. 총 20쪽의 발표 자료이며, 프로젝트 사양서와 구분해 보관합니다.

**[포트폴리오 PDF 보기](GEM_project_portfolio.pdf)** · [PDF 다운로드](GEM_project_portfolio.pdf?raw=true)

## 주요 내용

- 서비스 개요와 한계, 기업 페르소나, 유저플로우·유스케이스·논리 ERD·와이어프레임
- 메인·국가별 분석·품목별 수요·생산 시나리오·모델 비교 화면의 역할
- 팀원별 기여와 회고, 구현 결과와 남은 과제, 인간 중심 의사결정 지원이라는 설계 철학
- 기술 부록: 데이터 구성·전처리, 모델 평가조건, 공통 예측 엔진
