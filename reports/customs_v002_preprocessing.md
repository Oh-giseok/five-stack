# 관세청 전처리 결과

이 문서는 v002 당시 처리 이력이다. 이후 남은 분류 보류도 해제했으며 현재 상태는 [v003 전수 대조 결과](customs_v003_all_country_product_review.md)를 따른다.

버전: v002 | 원본: collection_20261103

관세청 원본과 사양서의 국가·HS·기간·USD FOB·kg를 대조하고 월별 HS6와 달력 분기별 패널을 생성했다. Comtrade·World Bank 연결과 시차·단가·학습 파일 생성은 이번 범위에 포함하지 않았다.

## 사양서 대조

| 항목 | 결과 |
|---|---|
| 국가 | YAML의 20개 대상국, alpha-2→ISO3 매핑 확인 |
| 제품 | YAML의 8개 HS6, 응답 코드의 접두·길이 확인 |
| 기간 | 2013-01~2026-09, 요청 범위 밖 행 없음 |
| 수출금액 | expDlr→export_value_usd, USD·FOB, 단위배율 1 |
| 순중량 | expWgt→export_net_weight_kg, kg, 임의 반올림 보정 없음 |
| 공개일·HS 판본 | 응답에 없어 null 유지, 과거 공개 근거·판본 확인은 별도 |

## 처리 결과

- 검증한 요청 2,240개, 원본 상세 46,594행.
- 명시적인 총계 2,160행을 집계에서 제외했다. 상세가 없는 성공 응답 80개는 월별 0으로 대체하지 않았다.
- 월별 HS6 패널 26,400행: {'actual': 23324, 'missing': 3052, 'partial': 24}.
- 분기별 HS6 패널 8,800행: {'actual': 7386, 'partial': 770, 'missing': 644}.
- 2026Q1~Q3 분기 정답 금액 확보 447/480행. 실제 테스트 파일로 분리하거나 학습에 투입하지 않았다.

## 미반환·부분 분기 처리

- 원천에 숫자 0이 있으면 0을 보존한다. 성공 응답에 상세가 없으면 금액·중량은 null이며 미거래·미신고·미공개를 임의 판정하지 않는다.
- 분기 내 3개월 모두 금액이 확인된 경우만 export_value_usd를 채운다. 중량도 같은 기준을 별도로 적용한다.
- 부분 분기의 관측 합계는 observed_export_value_usd·observed_export_net_weight_kg에 보관한다. 이 열을 분기 정답으로 사용하지 않는다.
- target_value_complete는 금액의 월별 완전성만 뜻한다. 예측 시점 공개 여부나 학습·검증 행 적합성까지 인증하는 플래그가 아니다.

## HS6·HS10 혼재 처리

- 원본 코드 길이별 상세: {'10': 46564, '6': 30}. 앞선 원본 소개의 46,594행 전체가 HS10이라는 설명을 바로잡는다.
- 혼재 월별 30행·분기별 12행 중 사용자 지시로 합산한 것은 월별 6행·분기별 2행이다.
- 나머지 월별 24행·분기별 10행은 금액·중량을 null로 보류했다. 해당 상세는 hs_level_review_details 파일에 보존했다.
- 사용자 합산은 products.yaml의 국가·제품·기간·원본 스냅샷 범위에만 적용했다. aggregation_rule_id·aggregation_decision_basis와 승인 상세를 보존하며 원천 중복 여부가 입증됐다고 표시하지 않는다.
- 아직 보류된 혼재 구간의 observed_* 값은 원본 비총계 행을 그대로 합한 검산용 수치다. 확정 정답으로 대체하지 않는다.

## 검증·남은 확인

- 원본 체크섬·요청 조건·국가·HS·기간·유일키·금액·중량 비음수와 원본→월별 관측합→분기 관측합 보존을 검증했다.
- 조회 총계와 상세의 수출금액 차이 0건. 수출중량 차이는 1284건, 최대 6kg로 기록했으며 원본 값을 수정하지 않았다.
- 금액이 양수이고 원천 중량이 0인 월 270개. 금액을 삭제하지 않았고 단가는 계산하지 않았다.
- API 현재 수정치를 사용한 스냅샷이다. released_at·release_evidence·hs_edition은 null이며 조회시각을 공개일로 대입하지 않았다.
- 원본과 최종 테스트 금액은 Git 공유 대상에 추가하지 않았다. 공개 보고서 CSV는 품질 플래그·누락 사유만 포함한다.
