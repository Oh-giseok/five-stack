# 관세청 6개 품목 보류·미반환 재검토

이 문서는 v002 당시의 보류 상태 기록이다. 이후 모든 국가·제품에 공통 집계를 적용해 분류 보류를 해제했으며, 현재 상태는 [v003 전수 대조 결과](customs_v003_all_country_product_review.md)를 따른다.

검토 대상: 아이 메이크업·스킨케어·기타 헤어케어·파우더·향수·피부세정제. 데이터 버전은 v002, 원본은 collection_20261103이다.
이번 검토에서는 전처리 기준·보류 상태·금액을 변경하지 않았다.

## 확인 결과와 처리 영향

- 원본 XML 1,680개와 수출 상세 38,081행을 정규화 상세와 독립 대조했다. 국가·코드·월·금액·중량·원본 경로가 일치했고 상세 행 삭제는 0개다.
- 보류는 원본이 없는 상태가 아니다. HS6·HS10이 혼재한 국가×제품×월의 최종 금액·중량을 null로 두었고, 이 월이 포함된 분기의 최종 금액·중량도 보류했다.
- 따라서 6자리 원본 24행만 따로 뺀 상태가 아니다. 같은 월에 반환된 10자리 60행의 금액도 월별·분기별 최종 타깃 열에서는 함께 보류돼 있다. 원본·상세·observed_* 검산 열에는 보존돼 있다.
- 24개 보류 월별 조합의 6자리 금액 합계는 118,713달러, 10자리 금액 합계는 672,781,017달러다. 전체 금액을 중복 여부가 해결된 확정 실적으로 해석하지 않는다.
- 24개 경우 모두 6자리 금액은 해당 월의 10자리 금액 합계와 다르다. 이 사실만으로 별도 거래인지 부분 중복인지 확정하지 않았다.

원본의 `기타` 명칭은 각 HS6 안의 세부 항목이다. 해당 세부 항목을 임의로 다른 제품군으로 이동하거나 삭제한 것은 없다.
스킨케어라는 표시명으로 사용 중인 330499에는 원본상 메이크업용·어린이용 제품도 포함돼 있다. 이 하위 항목도 보존했다.

예를 들어 헤어케어는 2016년 11월의 6자리 행 4달러와 10자리 세부 행 3,450,777달러가 함께 반환됐다. 해당 월 합계를 null로 보류하면서 2016Q4 전체 타깃도 보류했다.
분기 보류 범위에는 같은 분기의 다른 정상 월도 포함되므로, 위 표의 월별 금액 합계가 분기별 보류 금액 전체를 뜻하지는 않는다.
