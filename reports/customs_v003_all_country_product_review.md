# 관세청 전체 국가·제품 분류·집계 대조 결과

현재 버전: v003. 원본 스냅샷: collection_20261103. v001·v002는 비교용으로 보존했다.

## 전체 대조 결과

- 20개국×8개 제품의 160개 조합, 2013년 1월~2026년 9월 전체를 같은 기준으로 검토했다.
- 원본 XML 2,240개와 수출 상세 46,594행을 독립적으로 다시 읽어 정규화 상세와 대조했다. 국가·월·원본 HS·품명·금액·중량·파일 경로가 일치한다.
- 원본의 25개 HS 코드·품명 조합을 지정된 8개 HS6 제품군에 모두 대응시켰다. 분류되지 않은 상세와 삭제한 상세는 0개다.
- 명시적인 총계 2,160행은 중복 합산 방지를 위해 제외했다. 상세가 있는 모든 요청에서 비총계 상세의 수출금액 합계가 원천 총계와 일치했다.
- HS6와 HS10이 함께 조회됐다는 이유로 보류하던 기준을 제거했다. 모든 국가·제품·기간에 동일한 HS6 집계를 적용했다. 분류로 인한 보류는 0개다.

분류는 원본 HS 앞 6자리와 설정된 제품군을 기준으로 한다. 표시명에 스킨케어·헤어 등의 단어가 있는지 여부로 하위 항목을 제외하지 않는다.
원본 코드를 특정 10자리 코드로 강제 변환하지 않으며, 원래 코드·품명과 공통 집계 근거를 보존했다.

## 이전 버전에서 복구된 범위

- v002의 남은 분류 보류 월별 24행·분기별 10행을 집계에 반영했다. 아이·스킨케어·기타 헤어·파우더·향수·피부세정제에 해당한다.
- 이미 반영했던 립의 월별 6행·분기별 2행은 그대로 유지했다. 원본에서 발견된 자리수 혼재 월별 30행·분기별 12행 전체가 현재 집계에 포함된다.
- v002와 비교해 바뀐 최종 금액·중량 셀의 위치는 기존 보류 범위와 정확히 일치한다. 나머지 수출금액·중량과 전체 관측 부분합은 변하지 않았다.

| 분류 때문에 보류된 월·분기 | 0 |

조회되지 않은 자료를 0으로 만들지 않았다. 원본에 숫자 0이 기록된 값은 보존했다.
일부 월만 있는 분기는 관측 부분합을 별도 열에 남기고 완전한 분기 금액으로 대체하지 않았다. 이는 코드 분류 보류와 구분한다.
2026Q1~Q3은 480개 국가×제품×분기 조합 중 금액이 3개월 모두 확인된 조합이 447개다. 이 수치는 분류 보류 해제와 별개인 원본 조회 범위다.
