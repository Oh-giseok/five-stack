## 승인과 확인 수준

사용자가 지도학습 자료를 확정·공유하도록 승인했다. manifest의 status는 released이며 실제 파일명·행 수·자료형·SHA-256을 기록했다. 이는 과거 최초 공개일·빈티지를 입증했다는 뜻이 아니다.
현재 수정치·기간 정렬 변수를 사용한다. 시장은 origin 동일 분기, 거시는 직전 달력연도이며 origin_cutoff_at은 null이다. 현재 자료 기반 실험으로 명시하고 과거 공개시점 재현 평가에는 별도 근거·가정이 필요하다.

정답이 없는 행은 적합·정답 평가에서 제외한다. 각 origin 이후 정답과 타깃 품질·보조 중량 등을 입력에 넣지 않는다. 입력은 manifest의 feature_columns로 제한하고 변환기는 매 학습 구간에서만 적합한다.

## 포함하지 않은 자료

- 2026Q1~Q3 최종 테스트 입력·정답: 팀장 로컬 별도 관리.
- 비지도학습용 데이터: 별도 작업, 이번 공유에 포함하지 않음.
- 원본·전체 통합표·API 인증키·개인 문서·로컬 환경: Git 공유에서 제외.

읽기·학습 기준은 [공유 README](../data/shared/v001/README.md)를 따른다. 검증 명령은 `python scripts/package_dataset.py --verify-only`다. 기존 원천·처리 v001/v002·비지도 후보는 보존했다.

공유본 검산에서 41,600개 표본의 87개 공유 열이 처리 v002와 정확히 일치했다. 모델 입력 57개에는 정답·타깃 품질 정보가 없고 최종 테스트·비지도 자료도 포함하지 않았다. CSV/Parquet·체크섬 검증과 자동 테스트 60개가 통과했다. 커밋 전 비무시 파일의 실제 인증키 일치 항목과 100MiB 이상 파일은 모두 0개였다. [검산 결과](shared_v001_audit.json)를 따른다.
