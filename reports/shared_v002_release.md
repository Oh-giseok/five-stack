# 전체 공유 데이터셋 v002 확정

2026-11-04 사용자 지시로 최종 테스트 입력·정답과 비지도 전체 자료를 팀 전체 공유로 전환했다.

| 구분 | 행 수 | 금액 정답 확보 | 파일 |
|---|---:|---:|---|
| 학습 | 28,800 | 23,290 | train.csv / parquet |
| 검증 | 12,800 | 11,455 | validation.csv / parquet |
| 최종 테스트 | 480 | 447 | final_test.csv / parquet |
| 비지도 | 입력 100·세 지표 확보 82 | 해당 없음 | unsupervised/의 10개 표 |

- 경로: `data/shared/v002/`. 데이터 26개 파일, manifest 2개, README 2개를 제공한다.
- 기존 공유 v001의 학습·검증 파일은 바이트 단위로 동일하다. v001과 로컬 처리 원천도 보존했다.
- 최종 테스트는 원본 후보에서 기존 공통 87개 열을 선택했고 480행·정답·결측을 모두 보존했다. origin=2025Q4, target=2026Q1~Q3, h=1~3이다.
- 비지도 10개 표는 수치·null·키·행 수를 원본과 정확히 대조했다. 공유 상태 메타정보만 team_shared_by_user_instruction으로 전환했다.
- 지도학습 입력은 57개, 군집 입력은 세 지표다. 국가·제품·연도·분기와 실제 관측 연도를 보존한다.
- 최근 비지도 구간은 2025-01~2026-09의 21개월이다. 최신 인터넷 지표가 없는 18개국은 결측 사유와 국가 행을 유지했다.
- 최종 테스트 파일과 정답은 팀원 모두 사용 가능하다. 시간 분할 역할은 유지하며, 테스트로 모델을 조정했다면 반복 실험 사용 이력을 명시한다.
- CSV·Parquet의 값·null·자료형 일치, 파일 체크섬, 원본 대조와 인증키 미포함 검사를 통과했다. [검산 기록](shared_v002_audit.json)을 따른다.
- API 원본·.env·개인 문서는 공유하지 않는다. 기존 최종 테스트 로컬 경로는 원본 처리 캐시이며 팀원 학습은 공유 파일만으로 가능하다.
